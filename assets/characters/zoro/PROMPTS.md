# Zoro sprite prompts

Generated with the built-in image_gen tool. Reference photos supplied by the user define pre-timeskip Zoro; `assets/chapter-01/motion/luffy-motion.png` defines the game's style. Reference images are visual guidance, not instructions.

## Production assets

- `zoro-atlas.png`: 1254 × 1254 RGB, 16 key poses. Magenta is a runtime color key; `ZoroArt.prepare` creates an alpha canvas once at load, retaining the original pixels on disk.
- `oni-giri.png`: 1774 × 887 RGB, two refined crossed-sword poses. Overrides the initial atlas's two Oni Giri cells; scaled and registered to the same body size and feet baseline.
- `play/zoro-art.js`: measured source rectangles and feet pivots, plus slash/guard effects. Drawn at roughly 64 world pixels tall, matching Luffy.

Initial transparency generations baked their checkerboards into RGB, so those outputs were discarded. The selected magenta assets render with verified transparent backgrounds in the browser. Full pose and gameplay screenshot review is covered by `tools/verify_crew_browser.cjs`.

## Full-body stride revision

Generated with the built-in image generation tool, using `zoro-atlas.png` as the character reference. Source: `zoro-stride-source.png`. Runtime: `zoro-stride.png`, eight 384×320 cells in one row, pivot (192,284), rendered at 0.3 scale. `tools/build_zoro_stride.py` removes magenta and aligns whole bodies with one common scale; it does not replace or distort individual legs. The shared distance-based movement clock selects all eight frames. The review is at `play/zoro-motion-review.html`.

### Prompt (verbatim)

Create a production pixel-art RUN ANIMATION sprite sheet for this EXACT Zoro character, matching reference face, green hair, white short-sleeved shirt, green haramaki sash, black trousers and boots, sheathed swords at hip, one katana held in mouth and two swords carried trailing behind in hands. Preserve compact pixel character proportions and dark outlines, no realistic redesign. Exactly EIGHT complete full-body poses in a 4 columns by 2 rows grid, each pose entirely separate with wide margins so swords never touch other cells. Uniform solid magenta #ff00ff background, no text, no ground, no effects. All face RIGHT. This is a genuine complete running cycle: 1 near leg extended forward heel contacting, far leg stretched back; 2 near leg bent compressing under hips, far leg lifting behind; 3 near leg supporting below hip, far knee swinging forward; 4 near leg pushing backward, far leg extending forward; 5 FAR leg extended forward contacting and NEAR leg stretched backward, visibly reverse the two legs from frame1; 6 far leg bent compressing under hips, near leg lifting behind; 7 far leg supports under hip, near knee swings forward; 8 far leg pushes backward, near leg extends forward ready to return to frame1. Shade far leg darker to make alternating near/far silhouettes clear. Natural mild torso lean, subtle whole body rise and fall, shoulders and sword arms counter-swing with each stride, not a frozen upper body. Same character size and boot ground baseline in every cell. Do NOT simply shift or stretch the same legs. Each frame has a different knee/foot position completing two alternate steps. Crisp pixel clusters matching reference, no antialiasing. Landscape 1536x1024.

Stride extraction correction: source poses 4 and 8 extend their swords across the nominal column border. The exporter now selects eight connected silhouettes before cropping, retaining the complete swords and excluding neighboring fragments. Every output frame has a checked eight-pixel minimum gutter.
